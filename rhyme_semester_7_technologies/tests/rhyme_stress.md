# Проверка рифм с учётом ударения

Из корня проекта запустите `make run_rhyme_stress`. Тест печатает для
`test_MiM.txt` и `tests/text2.txt` долю найденных глагольных форм и вхождений
с известным ударением, число пар до и после изменения и число пар,
для которых сработала прежняя оценка из-за неизвестного ударения.
Пороги остались равны 50 для веса глагола и 0,5 для оценки рифмы.

В `mim_rhyme_pairs.tsv` сохранены 120 пар из ручной проверки исходного
отчёта и 12 дополнительно размеченных пар, пропущенных исходным алгоритмом.
Единица разметки — пара словоформ в контексте `test_MiM.txt`.

- `rhyme` — обе формы употреблены как глаголы и рифмуются от ударной гласной.
- `sound` — обе формы употреблены как глаголы, звучание расходится.
- `pos` — хотя бы одна форма в исходной паре употреблена как другая часть речи.
- `uncertain` — спорная пара, исключаемая из расчёта метрик.

Матрица ошибок учитывает этап распознавания глагола. Например,
«покажу — скажу» считается пропуском, если анализатор частей речи
отсеял одно из слов. Пары с метками `sound` и `pos`, принятые алгоритмом,
считаются ложными срабатываниями. Метрики описывают эту выборку.
Для оценки полноты по всему тексту нужна представительная разметка
пар, которые оба алгоритма отсеяли.
