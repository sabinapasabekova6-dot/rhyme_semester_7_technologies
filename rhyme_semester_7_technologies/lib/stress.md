# Ударения глагольных форм

`stress.txt` содержит 20 000 словоформ. В каждой строке записаны слово и
номер ударной гласной, считая слева с единицы. Например, запись
`поняла 3` соответствует «поняла́». Буква «ё» хранится в словарном написании.

Источник данных — [глагольный TSV OpenRussian.org](https://github.com/Badestrand/russian-dictionary/blob/master/verbs.csv)
от Badestrand и участников проекта. Исходник и производная таблица
распространяются по [CC BY-SA 4.0](https://creativecommons.org/licenses/by-sa/4.0/).
При подготовке таблицы были извлечены инфинитивы, формы прошедшего,
настоящего и будущего времени и повелительного наклонения. Номера ударных
гласных рассчитаны по пометам источника. Из форм с одним вариантом
произношения после нормализации «ё» → «е» взяты первые 20 000 в порядке
исходной таблицы и отсортированы по слову.

Для повторной сборки из скачанного `verbs.csv` запустите команду из корня проекта.

```sh
python3 lib/build_stress.py verbs.csv
```
